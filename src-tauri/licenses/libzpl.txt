libzpl 0.1.10

License texts for libzpl, the library Marlin draws label previews with.
libzpl is built from go-zpl (https://github.com/StirlingMarketingGroup/go-zpl).

This file is kept by hand. Its first line names the libzpl release it was
written for, and `npm run check:licenses` fails when the zpl-rs crate in
src-tauri/Cargo.lock has another version. To update it, run
`go version -m` on the new library, compare the list with the parts below,
and read `render/font.go` in go-zpl for the embedded fonts.

Three embedded fonts have no license text here, because go-zpl states none:
OCRB, Monospace 821 Bold BT, and Triumvirate Cond Bold. THIRD-PARTY-NOTICES.md
names their owners.
